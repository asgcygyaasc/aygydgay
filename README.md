# 微信账号专题文章库

本仓库采用扁平化 Markdown 文章结构，参考目标仓库的“单篇文章 = 根目录一个 `.md` 文件”展示方式，但不复制其文章内容。

- 共生成 900 篇文章
- 标题统一保留 `【关键词】` 占位符
- `keywords.txt` 预留 192 个关键词，生成时循环使用
- 每篇正文顶部固定加入 `TG:qszxc686`
- 提供 `generate_articles.py`，可批量重新生成、替换关键词

## 批量替换 192 个关键词

把你自己的 192 个关键词按“一行一个”写入 `keywords.txt`，运行：

```bash
python generate_articles.py
```

脚本会按顺序循环使用 192 个关键词：第 1 篇用第 1 个，第 193 篇重新使用第 1 个，以此类推。

如果只想修改现有标题中的关键词，也可以运行：

```bash
python generate_articles.py --replace-only
```

> 文章主题以微信账号的注册、绑定、安全、登录、迁移、运营、风控、隐私与使用技巧为主，不包含账号交易操作指南。
